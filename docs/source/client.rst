GPPClient
=========

:class:`~gpp_client.GPPClient` is the entry point. It holds one domain for each
area of GPP, such as ``client.program``, and the lower-level GraphQL and
REST clients that the domains use. For a first call, see
:doc:`getting-started`. For its arguments and the other places you can set
them, see :doc:`guides/configuration`.
